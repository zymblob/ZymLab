# 🧪 ZymLab

> 💻 A personal workspace for projects, calculations, and coding experiments.

**ZymLab** is a personal web-based project dashboard developed by **Edzymon Waga**, a first-year Computer Science student at Ateneo de Davao University. It brings together several JavaScript programming activities into one organized, interactive, and visually designed website.

Designed with a minimalist dark navy and white aesthetic, ZymLab focuses on **functionality, purposeful motion, subtle depth effects, accessibility, and user-friendly design.**

## ✨ Features

### 🌡️ 1. Conversion Calculator
A tool for converting measurements and temperatures between different units.

- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Meters to Feet
- Feet to Meters

### 💰 2. Income Tax Calculator
Calculates Philippine income tax based on taxable income and the provided tax brackets.

- Automatic tax computation
- Applicable tax bracket identification
- Computation breakdown
- Philippine Peso formatting

### 🔢 3. Loops & Number Operations
Demonstrates fundamental JavaScript looping structures through mathematical calculations.

- **Factorial** — `While Loop`
- **Sum of First N Natural Numbers** — `Do While Loop`
- **Average of First N Natural Numbers** — `For Loop`

### 🧾 4. Simple Payroll System
A basic payroll management tool for handling employee records and calculating salaries.

- ➕ Add employees
- 📋 Display employee payroll records
- 💵 Calculate gross pay
- ➖ Calculate deductions
- 💸 Calculate net pay
- 🗑️ Delete employees by line number
- 📊 View payroll summaries
